Blink Hunters: finding moving and changing objects in SPHEREx data¶

NASA Space Apps 2026 · Challenge: "Planet X and SPHEREx"

This notebook reproduces, step by step, what the Blink Hunters web tool does, and checks its results on the challenge's test targets: Barnard's Star, Epsilon Indi B, WISE 0855, RW Aurigae and R Draconis.

  1. Resolve a target and correct for proper motion
  2. Find every SPHEREx exposure covering it (DR1 + QR3)
  3. Look inside one exposure (image, flags, zodiacal light, per-pixel wavelength)
  4. Build per-visit stacks and blink / difference them
  5. Match wavelengths across visits (SPHEREx's 102 channels)
  6. Spectra on the fly from every exposure
  7. Brightness over time (RW Aurigae)
  8. Position over time (WISE 0855, blended with a background star)
  9. Gaia DR3 check, and partner data from CSA's NEOSSat

The notebook reuses the app's pipeline (backend/app/). Views built earlier are cached in cache/, so it runs in about a minute; on a fresh machine the first run downloads the stamps (several minutes per target).

1. SPHEREx in one table¶

SPHEREx maps the whole sky about every 6 months from 0.75 to 5 µm. Six detectors each sit behind a linear variable filter: the wavelength changes smoothly across the detector, so each exposure sees a star at a slightly different wavelength. Seventeen channels per detector give the "102 bands". Pixels are large (6.15″).

2. Targets and proper motion¶

Catalogue (J2000) positions of nearby stars are badly out of date. Barnard's Star has moved 4.5 arcminutes since 2000, more than half of a 6′ cutout. The app moves every target to epoch 2026.0 before searching.

4. Inside one exposure¶

Each exposure has image, flags, variance, zodiacal-light and per-pixel wavelength layers. The app reads only a small stamp around the target from the public AWS copy, skipping the big PSF cube that the cutout service always sends (~4–5 MB per exposure).

5. Blink and difference: Barnard's Star¶

The app aligns every stamp onto one sky grid (zodi subtracted, bad flags masked, background levelled), stacks each visit per detector with inverse-variance weights, and renders all frames with one shared brightness scale. In the difference frames a moving star becomes a black/white pair.

In [6]:
def build(label, per_group=0):
    key = pipeline.start_view(pipeline.PRESETS[[p["label"] for p in pipeline.PRESETS].index(label)]["query"], 0.1, per_group)
    state = pipeline.job(key)
    while state["status"] not in ("done", "error"):
        import time; time.sleep(2); state = pipeline.job(key)
    assert state["status"] == "done", state
    return key, state["manifest"]

def show_frames(key, m, files, titles, scale=4):
    fig, ax = plt.subplots(1, len(files), figsize=(3.2 * len(files), 3.4))
    for a, f, ti in zip(np.atleast_1d(ax), files, titles):
        a.imshow(np.asarray(Image.open(config.VIEW_DIR / key / f)), cmap="gray", origin="upper")
        a.set_title(ti, fontsize=9); a.set_xticks([]); a.set_yticks([])
    plt.show()

def gif(key, files, path, ms=600, scale=5):
    ims = [Image.open(config.VIEW_DIR / key / f).convert("L") for f in files]
    ims = [im.resize((im.width * scale, im.height * scale), Image.NEAREST) for im in ims]
    ims[0].save(path, save_all=True, append_images=ims[1:], duration=ms, loop=0)
    return IPImage(filename=str(path))

6. Matching wavelengths across visits¶

Within one detector the wavelength still varies a lot (D4 spans 2.4–3.8 µm). A Space Apps Navigator advised matching wavelengths before blinking, so a colour difference isn't mistaken for motion or variability. The app splits each detector into 17 log-wavelength channels and blinks only exposures from the same channel.

7. Spectra on the fly¶

Clicking any object measures it in every exposure (aperture photometry, local background subtracted), giving a spectrum of up to 102 wavelengths. Barnard's Star itself is saturated (flagged) in almost every exposure, so here is a field star in the same view.

In [9]:
w, shape = frames.grid_wcs(m_b["target"]["ra"], m_b["target"]["dec"], m_b["fov_deg"])
s = np.load(config.VIEW_DIR / key_b / "stack_Dall.npz")["v0"]
n = shape[0]; c = n // 2; yy, xx = np.indices(s.shape)
s2 = np.where(np.isfinite(s), s, -np.inf); s2[np.hypot(xx - c, yy - c) < 8] = -np.inf
s2[:8] = s2[-8:] = -np.inf; s2[:, :8] = s2[:, -8:] = -np.inf
y, x = np.unravel_index(np.argmax(s2), s.shape)
star = w.pixel_to_world(x, y)

pts, flagged = pipeline.view_spectrum(key_b, star.ra.deg, star.dec.deg)
pts_b, flagged_b = pipeline.view_spectrum(key_b, m_b["target"]["ra"], m_b["target"]["dec"])

8. Brightness over time: RW Aurigae¶

RW Aur is a young star with a dusty disk. Between visits it gets brighter at short wavelengths and fainter at 4–5 µm, a colour change, which is why comparing within one detector (or channel) matters.

9. Position over time: WISE 0855, the coldest known brown dwarf¶

WISE 0855 moves 8.1″/yr but is almost invisible below ~3.5 µm. In SPHEREx it shares a pixel with a background star (Gaia G = 16.3, 6.8″ away). The light centre shows the blend:

  • D1–D4 (short wavelengths, the background star): fixed.
  • D5–D6 (4–5 µm, the brown dwarf): drifts west by about 5″ in a year (diluted by the blend).

The spectrum at that spot shows the brown dwarf's 4–5 µm peak.

10. Cross-check with Gaia DR3¶

Gaia stars, moved from epoch 2016.0 to 2026.0, should land on the SPHEREx stars. That tests our alignment, and Gaia's proper motion for Barnard's Star predicts the motion seen in the difference images.

11. Partner data: CSA NEOSSat¶

NEOSSat (Canadian Space Agency) is an optical space telescope for asteroids and comets. Its images, archived at the Canadian Astronomy Data Centre, cover all five test targets (about 2019–2023). Together with SPHEREx (2025–2026) that's a ~6-year baseline. The query takes ~40 s per target, so only Barnard's Star is run here.

In [13]:

Summary¶

All changes are candidates: check flags, compare within one detector or channel, and confirm with other data (Gaia, NEOSSat, WISE) before calling anything a discovery.
